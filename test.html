Mantra MFS110 L1 RD Service

Fingerprint Data Viewer

Apne Mantra L1 fingerprint device se capture kiye gaye exact data ko dekhiye. Device se jo bhi response milta hai, sab kuch yahan parsed aur raw XML dono format mein.

ⓘ Kaise Use Karein

  1. Mantra RD Service install karein aur MFS110 device ko PC se connect karein.
  2. "Device Discover Karein" button dabayein. Ye localhost ports 11100-11120 aur HTTPS 11200 pe RD Service ko dhundhega.
  3. Device milne ke baad "Fingerprint Capture Karein" button dabayein aur apna finger scanner pe rakhein.
  4. Exact data jo device se milta hai, neeche dikh jayega: Resp, DeviceInfo, Skey, Hmac, Data (PID block) sab kuch.
